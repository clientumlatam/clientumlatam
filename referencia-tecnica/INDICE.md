# Referencia Técnica — Índice

Carpeta de referencia del proyecto Clientum con código fuente archivado, capturas, documentación y assets.

## Estructura

| Carpeta | Contenido |
|---------|-----------|
| `1-wordpress/tema/` | Tema PHP clientum-theme (templates, style.css) |
| `1-wordpress/plugins/` | Plugins WordPress activos y archivados |
| `1-wordpress/woocommerce/` | Versiones anteriores de WooCommerce |
| `2-codigo/raiz-wordpress/` | Archivos raíz del WordPress original |
| `2-codigo/raiz-replit/` | Archivos raíz del proyecto Replit |
| `3-sitio-web/html/` | Páginas HTML del sitio (comparativas, servicios, socios) |
| `3-sitio-web/sitemaps/` | Sitemaps del sitio |
| `4-agentes/fichas/` | Fichas de configuración de agentes IA |
| `4-agentes/prospector-app/` | App prospector |
| `4-agentes/replit-vercel/` | Config Replit ↔ Vercel |
| `4-agentes/scripts/` | Scripts de automatización |
| `4-agentes/catalogo-csv/` | CSVs del catálogo de servicios |
| `5-docs/` | Documentación markdown, arquitectura, roadmap |
| `5-docs/sesiones/` | MDS consolidado de sesiones |
| `5-docs/historial/` | Historial de cambios y auditorías |
| `5-docs/neon-console/` | Exports del panel Neon |
| `6-assets/brochures/` | Brochures HTML/PDF |
| `6-assets/capturas-proceso/` | Capturas de proceso/deployment |
| `6-assets/chats-exports/` | Exports de chats Claude/ChatGPT |
| `6-assets/imagenes/` | Imágenes sueltas |
| `6-assets/logos/` | Logos de Clientum |
| `6-assets/exports/` | Exports WordPress, scaffolds |
| `7-capturas-sitio/sitio-web/` | Capturas actuales del sitio web |
| `7-capturas-sitio/sitio-web-historico/` | Capturas históricas del sitio |
| `7-capturas-sitio/replit/` | Capturas del entorno Replit |
| `7-capturas-sitio/assets-chat/` | Imágenes adjuntas de sesiones de chat |
| `_zips/` | Archivos comprimidos originales (.zip) |
