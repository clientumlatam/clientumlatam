# Proceso — Orquestador IA

1. Jonathan da una instrucción por chat
2. Identifico qué agente departamental la resuelve (Técnico/Ventas/Marketing/CS/Operaciones)
3. Coordino flujos multi-agente/multi-departamento cuando la tarea cruza áreas
   (ej: un lead cerrado por Ventas dispara trabajo en Técnico)
4. Reviso el tablero cada 15 min; si un agente quedó trabado, reasigno o alerto
5. Cuando el objetivo se completa, le aviso a Jonathan UNA vez con el resultado
6. Actualizo memoria.md con el historial de instrucciones y resultados
